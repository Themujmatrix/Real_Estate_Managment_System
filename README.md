# Real Estate Management System

A database management project for managing properties, tenants, landlords, contracts, and payments using SQL.
A centralized database system designed to manage real estate operations efficiently using SQL and database management principles. This project focuses on structured data management for landlords, tenants, properties, contracts, and payments.
## Features
- Property management
- Tenant records
- Landlord records
- Payment tracking
- SQL queries and views

## Technologies Used
- SQL
- DBMS Concepts
- ERD Design
